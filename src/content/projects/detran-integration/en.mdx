## Context

Web application integrated with Detran (Brazil's state traffic authority), developed over more than 3 years, combining continuous product evolution, code quality and collaboration with multiple stakeholders. It was also the project where I grew from junior to mid-level developer.

## My role

Front-end Developer working across the whole cycle: planning, requirements analysis, technical solution design, development, testing and continuous evolution of the application.

## Key challenges

- Keeping a product **constantly evolving for over 3 years** without accumulating technical debt that would slow down deliveries.
- Integrating with **government traffic authority services**, handling API contracts and diverse error scenarios.
- Aligning requirements with **multiple stakeholders** (product, design, backend) in a domain with very specific rules.

## Solutions implemented

- Built front-end solutions with **React 18, TypeScript and Emotion Styled**.
- Implemented **tests with Jest**, tracked coverage and applied linting standards.
- Documented components in **Storybook** and integrated APIs through **Swagger-based contracts**.
- Actively participated in **planning, requirements analysis and technical solution definition**.
- Collaborated closely with **design and backend** teams to ensure functionality and performance.

## Results

- Application kept healthy and evolving for over 3 years, with code quality sustained by tests and documentation.
- Professional growth from junior to mid-level within the project, gradually taking on higher-impact technical decisions.
- A documented component base that made onboarding new developers easier.
