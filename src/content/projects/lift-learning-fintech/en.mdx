## Context

Financial technology web application created through the LIFT Learning program — an initiative involving Fenasbac and the Central Bank of Brazil — focused on innovative solutions for Brazil’s financial system. The product required an interactive table manipulation experience inspired by spreadsheet capabilities.

## My role

As a Full Stack Engineer, I built the application from the ground up according to client requirements, implementing the table experience on the frontend and supporting full-stack delivery with Python and Django REST Framework.

## Key challenges

- Delivering an application **from scratch**, aligned with client requirements and the program schedule.
- Implementing a complex **interactive table interface** inspired by spreadsheet capabilities.
- Coordinating frontend and backend work in a context of **agile ceremonies** and continuous requirements validation.

## Solutions implemented

- Built the application with **React.js, TypeScript, and Chakra UI**, focused on frontend architecture and data table interfaces.
- Supported full-stack delivery with **Python and Django REST Framework** and REST API integration.
- Participated in **planning, daily meetings, and retrospectives** to coordinate implementation, validate requirements, and deliver on schedule.
- Used practices and tools such as **Storybook, Jest, and Docker** in the quality and delivery workflow.

## Results

- Product delivered within the expected LIFT Learning project schedule.
- Interactive table experience aligned with client needs and the financial domain.
- Coordinated full-stack delivery with continuous requirements validation throughout the agile cycle.
