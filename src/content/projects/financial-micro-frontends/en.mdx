## Context

Financial services web application in constant evolution, with multiple teams working in parallel. The central challenge: deliver scalable, production-quality interfaces while modernizing the frontend architecture without compromising visual consistency or platform maintainability.

## My role

As a Senior Software Engineer, I develop and evolve the application with responsibility for scalable user interfaces, reusable components, production-quality code, and continuous modernization of the frontend architecture.

## Key challenges

- Evolving the frontend architecture with **Micro Frontends and Module Federation**, enabling independent teams to ship without conflicts.
- Ensuring **visual consistency and maintainability** through a Design System, tokens, and component documentation.
- Sustaining **production quality** with automated tests, coverage tracking, and reliable REST API integration.

## Solutions implemented

- Built and evolved interfaces with **React.js and TypeScript**, focused on reusable components and production-quality code.
- Implemented a **Micro Frontend architecture with Module Federation** and contributed to the Design System via **Style Dictionary**, reusable component patterns, and **Storybook** documentation.
- Built automated tests with **Jest**, monitored coverage, and integrated REST APIs documented with **Swagger/OpenAPI**.
- Supported delivery workflows with **Docker, Nginx, Git, and linting**, collaborating with Product, Backend, QA, and Design teams.

## Results

- Greater visual consistency and maintainability across modules and teams.
- Reduced regression risk through tests, coverage, and quality practices in the delivery workflow.
- A modernized frontend architecture able to evolve continuously in a financial domain where stability is critical.
